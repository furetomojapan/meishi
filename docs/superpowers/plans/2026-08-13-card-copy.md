# 名刺コピー機能（管理画面） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理画面のLibrary一覧から、既存ユーザーの名刺内容・デザイン・プラン・タグ等をすべてコピーして、新しいIDの別ユーザーとして複製作成できるようにする。

**Architecture:** バックエンド（`gas_backend.js`）は変更しない。フロントエンドから既存の管理者向けルート（`admin_create_user` → `admin_save_user` → 必要なら `admin_set_trial`/`admin_set_pro` → 必要なら `admin_save_tags`）を順番に呼び出すオーケストレーションとして実装する。新しいIDの入力には、既存の数値専用モーダル`appPrompt`をテキスト入力にも対応させて再利用する。

**Tech Stack:** React（`src/App.jsx`・`src/lib/dialog.jsx`）、既存のGAS Web App API（変更なし）。

## Global Constraints

- バックエンド（`gas_backend.js`）・GASデプロイは対象外。フロントエンドのみの変更（`src/App.jsx`・`src/lib/dialog.jsx`）
- 新しいIDのバリデーションは既存の「新規ユーザー追加」入力と同じ：半角英数字・アンダースコアのみ、`registeredNames`と重複不可、空不可
- コピーする：`displayName` / `links` / `profile`（デザイン全般・独自背景画像URL込み） / `plan` / `plusG` / `trialEnd`・`proEnd`の残り日数（未期限切れの場合のみ） / タグ
- コピーしない：PIN・`publicId`・`tagPublicId`・`licenseKey`
- このプロジェクトにフロントエンド用の自動テスト基盤はない（`tests/gas_mock_test.cjs`はバックエンドのみ対象）。各タスクの検証は `npx eslint src/**/*.jsx` と、精緻な手動確認手順で行う
- 変更のたびに `docs/session_log.md` へ追記する（プロジェクトの開発ルール）

### Task 1: `appPrompt`をテキスト入力にも対応させる

**Files:**
- Modify: `src/lib/dialog.jsx`

**Interfaces:**
- Consumes: なし（既存の`appPrompt`/`DialogHost`の内部実装のみ変更）
- Produces: `appPrompt(opts)` が新たに受け付けるオプション：
  - `opts.inputType`: `"number"`（デフォルト、既存動作） | `"text"`（新規）
  - `opts.sanitize`: `(raw: string) => string`（`inputType:"text"`の時のみ使用。入力のたびに呼ばれ、返り値が入力欄に反映される。省略時はそのまま）
  - `inputType:"text"`時、確定すると `close(input.trim())` で**文字列**を返す（数値変換・floor処理はしない）。キャンセル時は従来通り`null`
  - 既存の呼び出し（`opts.inputType`省略＝`"number"`）の動作は一切変えない

- [ ] **Step 1: `appPrompt`のフォールバック分岐（`_show`未マウント時）をテキスト対応にする**

`src/lib/dialog.jsx`の`appPrompt`を以下に置き換える：

```js
export const appPrompt = (opts) => new Promise((resolve) => {
  if (_show) _show({ ...opts, prompt: true, resolve });
  else {
    const v = window.prompt(opts.message, opts.default ?? "");
    if (v === null) { resolve(null); return; }
    resolve(opts.inputType === "text" ? v.trim() : (Number(v) || 0));
  }
});
```

- [ ] **Step 2: `DialogHost`の`submitInput`をテキスト対応にする**

同ファイル内、`DialogHost`関数の`submitInput`を以下に置き換える：

```js
  const submitInput = () => {
    if (dlg.inputType === "text") { close(input.trim()); return; }
    const n = Math.max(0, Math.floor(Number(input) || 0));
    close(n);
  };
```

- [ ] **Step 3: 入力欄（`<input>`）をテキスト対応にする**

同ファイル内、`{dlg.prompt && (...)}`ブロック内の`<input type="number" ...>`を含む`<div className="flex items-center gap-2">`ブロックを以下に置き換える（`type`・`onChange`のサニタイズ処理・`inputMode`/`min`の出し分けが変更点）：

```jsx
            <div className="flex items-center gap-2">
              <span className="text-[11px] text-neutral-500 whitespace-nowrap">{dlg.inputLabel || "任意の値"}</span>
              <input
                type={dlg.inputType === "text" ? "text" : "number"}
                inputMode={dlg.inputType === "text" ? "text" : "numeric"}
                min={dlg.inputType === "text" ? undefined : 0}
                value={input} autoFocus
                onChange={(e) => setInput(dlg.inputType === "text" && dlg.sanitize ? dlg.sanitize(e.target.value) : e.target.value)}
                onKeyDown={(e) => { if (e.key === "Enter") submitInput(); }}
                className="flex-1 w-full px-3 py-2 bg-neutral-50 border border-neutral-200 rounded-xl focus:outline-none focus:border-black text-sm text-center font-mono" />
              {dlg.unit && <span className="text-[11px] text-neutral-500">{dlg.unit}</span>}
            </div>
```

- [ ] **Step 1: `copyUser`関数を追加する**

`src/App.jsx`の`fetchAllTags`定義（13行目付近、`const fetchAllTags = async (pass) => {...};`）の直後に、以下の関数を追加する：

```js
        // ── 管理者: 名刺コピー（内容・デザイン・プラン・タグ等を丸ごと複製） ──
        const copyUser = async (sourceName) => {
          const pd = getPersonData(urlsData, sourceName);
          const newId = await appPrompt({
            message: `「${pd.displayName || sourceName}」の内容をコピーして新しいユーザーを作成します。\n新しいID（半角英数字・アンダースコアのみ）を入力してください。`,
            inputLabel: "新しいID",
            inputType: "text",
            sanitize: v => v.replace(/[^a-zA-Z0-9_]/g, ""),
            default: "",
          });
          if (newId === null) return; // キャンセル
          const id = String(newId).trim();
          if (!id) return;
          if (registeredNames.includes(id)) { await appAlert("このIDはすでに存在します"); return; }

          showToast("saving", 20000);
          try {
            const r1 = await gasPost({ action: "admin_create_user", adminPass: adminPassLocal, name: id });
            if (!r1.success) { showToast("error"); return; }

            const r2 = await gasPost({
              action: "admin_save_user", adminPass: adminPassLocal, name: id,
              displayName: pd.displayName, licenseKey: "", links: pd.links,
              plan: pd.plan, profile: pd.profile, plusG: pd.plusG,
            });
            if (!r2.success) { showToast("error"); return; }

            const tDays = trialDaysLeft(pd);
            if (tDays > 0) await gasPost({ action: "admin_set_trial", adminPass: adminPassLocal, name: id, days: tDays });

            const pDays = proDaysLeft(pd);
            if (pDays > 0) await gasPost({ action: "admin_set_pro", adminPass: adminPassLocal, name: id, days: pDays });

            const srcTags = adminAllTags[sourceName] || [];
            if (srcTags.length > 0) await gasPost({ action: "admin_save_tags", adminPass: adminPassLocal, name: id, tags: srcTags });

            await fetchAllUsers(adminPassLocal);
            await fetchAllTags(adminPassLocal);
            showToast("saved");
          } catch { showToast("error"); }
        };
```
